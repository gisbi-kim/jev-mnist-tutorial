# 요청 변화 기록

현재 대화에 제공된 사용자 발언을 근거로 요지를 정리했습니다. 전체 대화 export가 아니며 사용자 발언별 정확한 시각은 제공되지 않았습니다.

1. 다운로드 폴더 학습 코드 점검 → 패키지 설치, 10-step 학습·저장 모델 재로딩.
2. 메모리가 약 2GB인 이유, 행동 정확도 46%/에피소드 성공률 0%의 의미, VLM·LoRA·decision head·Clef 설명.
3. 데이터와 step 확대, 검증·GPU 메모리 보고. 큰 batch의 속도 효과 확인.
4. 데이터 실제 예시와 자연어 표현 다양성 설명. 다양성 자체의 확대를 요구한 것은 아님.
5. 웹에서 각 batch의 데이터 쌍, loss, prediction, loss plot과 평균선 공개.
6. 영어 입력 고정. state와 questions를 합쳐 목표와 선택지가 충분히 설명되는지 확인.
7. 대시보드 투명성 강화. 작은 데이터 암기 진단과 더 큰 batch 실험.
8. 암기 실험과 본학습에서 다룬 숫자·이미지 범위 구분. train/eval/test 상세 설명.
9. 전체 test 10,000장 및 실패 상황 대시보드 요청.
10. 시간 때문에 **1,000장으로 축소**, 실패에서 배우는 보고서와 inference time 측정.
11. 코드·config·정리된 요청·모든 로그를 한 폴더로 묶어 튜토리얼 사이트 재료로 준비.
12. 범위 질문에 **'정적 사이트 초안까지 함께 제작'**으로 답변.

미실행 계획: 2B 비교, 다양한 seed 반복, 전력/금액 비용, 새 필체와 큰 테스트 확장, 원인 분리 ablation. 이번 패키징에서 추가 GPU 학습/추론을 수행하지 않았습니다.
