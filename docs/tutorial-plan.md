## 문장과 화면 구성

2026-10-30에 본문을 기술 실험 기록 형태로 다시 작성하였다. 문장은 ‘~이다/~하였다’ 체로 통일하고, 개념을 정의한 뒤 코드와 관찰 결과를 설명하도록 구성하였다. 초기 학습 실패의 원인은 확정하지 않고, 관찰한 결과와 추후 검증할 가설을 구분한다. 큰 홍보 문구와 카드식 도입부는 일반적인 제목, 문단, 목차로 바꾸었다.

사용자가 참고 자료로 지정한 [다크 프로그래머](https://darkpgmr.tistory.com/)에서 문제를 설명하고 번호가 있는 절을 따라 구현과 결과를 살펴보는 전개 방식을 참고하였다. 원문 문장은 옮기지 않았다.

기존 배치 탐색기, 확률 예제, 실패 사례 필터는 본문 안에 유지하였다. 원본 로그와 실험 데이터는 문체 수정 대상에 포함하지 않았다. 사이트는 로컬에서 제공되며 외부 배포는 수행하지 않았다.
